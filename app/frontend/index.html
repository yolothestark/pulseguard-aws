Regla 2: Chaos Engineering en Vivo

Simulador de Pruebas de Resiliencia y Tolerancia a Fallos

Ejecuta fallos controlados en vivo para demostrar cómo el Application Load Balancer (ALB), Amazon SQS y la Dead Letter Queue (DLQ) evitan que el sistema se rompa.

Escenario 1: Alta Disponibilidad EC2 ALB Multi-AZ

Caída de Servidor Web (EC2)

Hace que el nodo actual reporte HTTP 503 en /api/health. El Load Balancer desvía el 100% del tráfico a la otra instancia EC2 sin interrumpir el servicio.

Escenario 2: Tolerancia a Fallos Asíncrona SQS + DLQ

Inyectar Mensaje Corrupto (Poison Pill)

Envía un evento que provoca una excepción crítica en AWS Lambda. SQS reintenta automáticamente y aísla el mensaje fallido en la Dead Letter Queue (DLQ).

Escenario 3: Prueba de Estrés Load Leveling

Ráfaga Masiva de Telemetría + Pico Crítico

Inyecta 30 eventos de telemetría simultáneos y una alerta crítica. SQS absorbe el pico en milisegundos con 0% pérdida de datos y dispara incidente + SNS.
